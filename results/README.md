# Результаты на Spider

Новые замеры на отдельной выборке из 2147 вопросов собраны в [Spider 1.0 test](spider_test/README.md).

Все пять вариантов оценены на одних и тех же 1034 вопросах Spider dev с одинаковой проверкой SQL. Разбивка по сложности приведена в JSON метрик для каждого варианта.

| Конфигурация | Проектная Execution Accuracy | Текстовый Exact Match | Valid SQL | Stop Rate |
|---|---:|---:|---:|---:|
| [Base zero-shot](base_0.5b_zero_eval_metrics.json) | 24,56% (254/1034) | 7,93% | 61,80% | 76,98% |
| [Base 4-shot](base_0.5b_few_eval_metrics.json) | 20,21% (209/1034) | 8,90% | 48,74% | 1,55% |
| [Исходный SFT zero-shot](sft_0.5b_zero_eval_metrics.json) | 49,42% (511/1034) | 31,62% | 73,60% | 99,90% |
| [SFT на расширенном датасете, zero-shot](sft_0.5b_expanded_zero_eval_metrics.json) | 48,65% (503/1034) | 30,56% | 72,73% | 99,71% |
| [Instruct zero-shot](instruct_0.5b_zero_eval_metrics.json) | 23,31% (241/1034) | 2,90% | 49,23% | 78,53% |

Base zero-shot и исходный LoRA измерены 17.11.2026 на Colab Tesla T4. В двух полных запусках совпали все сохранённые ответы. Методика, окружение и контрольные суммы описаны в [docs/evaluation.md](../docs/evaluation.md).

Три дополнительных замера от 22.11.2026 выполнены на Colab Tesla T4. Расширенный LoRA обучен на 8222 примерах, включая 1659 из train_others. В base 4-shot добавлены четыре фиксированных примера из тренировочных баз, по одному на уровень сложности. Для Instruct содержание исходного запроса передано в штатном формате чата Qwen без демонстрационных примеров.

После пересчёта v3 расширенный LoRA дал 503 совпадения, исходный LoRA — 511. На уровне extra результат вырос с 34 до 45 совпадений из 166. В этой конфигурации Base 4-shot набрал на 4,35 п. п. меньше Base zero-shot.

Воспроизведение дополнительных замеров описано в [Colab-ноутбуке](../notebooks/colab_followup.ipynb). JSON метрик новых запусков содержат версии моделей, SHA-256 входов и ответов и настройки окружения. Все 3102 новых ответа повторно проверены выполнением SQL, итоговые флаги совпали.

Файлы *_eval.jsonl содержат все ответы и результаты проверки. Отчёты обучения на Kaggle и сведения об окружении исходных замеров хранятся в этом каталоге. Данные Spider, экспериментальные архивы и веса хранятся отдельно.
